Raw Depth Feed (2D) Visualizing blockiness and sensor noise

Raw Depth Feed

How to read: This simulates the raw 2D depth map captured by the sensor. The grid corresponds directly to the sensor resolution (e.g., 160x120).

Color representation: Lighter colors represent closer objects, and darker colors represent objects further away. The amber hue helps distinguish the foreground object from the grayscale background wall.

Interactive Point Cloud Back-projected 3D scene (Orbit/Zoom)

Interactive Point Cloud

How to read: This is the resulting 3D geometry after applying the back-projection equations. You can orbit, pan, and zoom to inspect the generated shape and any distortions introduced.

Color representation: A Z-axis heatmap is used. Orange/Red points represent geometry closer to the camera, transitioning through yellow/green to Blue for points further away.

Frustum Cross-section Density vs Distance Visualization

Frustum Cross-section

How to read: A top-down view showing how camera rays spread outward. The gap between lines illustrates how point density drastically drops as an object moves further away.

Color representation: The amber box represents the target object. The expanding gray cone lines represent individual pixels/rays cast from the sensor.

Flying Pixel Edge Visualizer Boundary artifact zoom-in

Flying Pixel Edge Visualizer

How to read: An extreme zoomed-in 3D view of the physical boundary where the foreground object ends and the background wall begins. It highlights "mixed pixels" that interpolate between the two depths.

Color representation: Orange points are the foreground object. Blue points are the background wall. Red points streaking between them are the erroneous "flying pixels".
